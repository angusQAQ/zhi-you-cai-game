# 實際驗證記錄

日期：2026-11-04（香港時間）。全部在使用者授權的雲端環境進行，沒有在教師電腦建立遊戲或伺服器。

## 已通過

- `npm run check`：**9 項測試，9 通過、0 失敗、0 跳過**。涵蓋題數、句式、唯一答案、兩次題庫更正、固定語意切分、標點、逐題角色、動作閘門、暫停排程、卡片交換、雙指卡片擁有權及錯誤保留。
- `python3 tests/browser.py`：**16 項瀏覽器情境通過**。Chromium 實際測試 1920×1080、1280×720 的全部 15 題；三個圖文選項、列車、題號及教師控制均可在視窗內操作。驗證答錯重試、答對後等待另一人、所有列車答案、雙觸控同時拖動、同卡防重複、移回詞庫、取消拖動、鍵盤替代、動畫逐格變化、凍結與恢復、跳題取消舊事件、重開、最後一題重溫及直接重溫。沒有瀏覽器例外或素材 HTTP 失敗。
- `python3 tests/audio_browser.py`：**3 項原生音訊生命週期情境通過**。測試路由內使用六秒測試聲音，驗證暫停保留 currentTime、動畫完成仍等待音訊、靜音中止後只推進一次、跳題及回首頁停止音訊。測試音不是配音，不隨成品發布。
- `python3 scripts/check_assets.py`：10 組各 16 幀情境圖、5 組列車雙圖及共用字型／詞義圖存在，尺寸與已檢查雜湊相符。每組動畫含 16 張不同像素幀。目視檢查記錄見 `art-manifest.json`，包含實際修圖後的最終版本。

畫面證據保存在 `evidence/`（關鍵 PNG 與結果已保留於專案，CI 亦上傳 artifact）。包括首頁、兩款第 1 題、生活第 6 題及列車高階題，分別為兩個指定解像度。機器可讀結果為 `evidence/browser-results.json`。
